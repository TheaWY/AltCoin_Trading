단계별 실행
Phase 0

소액 계좌 현실화

PAPER_STARTING_CAPITAL=730, 수수료, 슬리피지, 최소주문, 예상 절대수익을 대시보드에 표시.

Phase 1

현재 셋업을 전부 백테스트 가능하게

mean_reversion, breakout, tsmom_28d를 registry 전략으로 승격.

Phase 2

델타 뉴트럴 펀딩 캐리

현물 롱 + 무기한 숏, 펀딩 현금흐름, 수수료 회수 기간, 청산 버퍼, 리밸런싱 구현.

Phase 3

그리드봇은 paper-only

ATR 기반 격자폭, 메이커 주문 가정, 추세장 중단 조건, 최소주문 제한 반영.

Phase 4

청산·롱숏비율 역추세

롱숏비율 + OI + funding + liquidation 조건을 조합한 crowding reversal 전략.

Phase 5

실험 전략

Pair trading과 listing-event mean reversion은 sandbox로만 추가.
